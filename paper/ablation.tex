Switching off one check at a time in setup C (Qwen, Table~\ref{tab:abl}) shows which checks carry the result on this test set. Without the validity check all seven flag questions become confidently wrong; without adaptive replications a single run replaces the confidence interval and correct answers drop from 37 to 28, mostly on numeric and choice questions; without the scope check three more out-of-scope questions are answered. Switching off the unit, paired-comparison or value check changes no answer: no test question needed a unit conversion of an input, and the paired verdicts were already clear without common random numbers.
